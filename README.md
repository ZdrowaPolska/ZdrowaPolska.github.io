# ZdrowaPolska.github.io

Compatibility site for legacy Zdrowa Polska GitHub Pages URLs.

Old URLs under:

`https://zdrowapolska.github.io/zdrowa-polska-signatures/...`

are redirected to:

`https://zdrowa-polska.github.io/zdrowa-polska-signatures/...`

This preserves QR codes already printed on employee business cards after the repository owner moved from `ZdrowaPolska` to `Zdrowa-Polska`.
